# CSC4001 Resources

Repository of presentations and worksheets for Systems and Architecture.

It is a quarto project. Please run
```
quarto render
```
to build all the files, or
```
quarto render CSC4001-S10-OS.qmd
```
to render just that specific file. 

The `docs` folder contains generated html files, and the `assets` folder contains images. 

The files are numbered according to session, with two sessions per week, but please note that not every session has a presentation because some of them were practical workshops, assessment sessions, or guest lectures from The Library or Academic Skills. Files with `W` are worksheets, e.g., `CSC4001-S02W` is a handout for students to work from.
